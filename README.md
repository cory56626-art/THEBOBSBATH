# BOB Paint

A fast, touch-friendly painting app that runs entirely in the browser.

**Open the app:** https://cory56626-art.github.io/THEBOBSBATH/

## Features

- Brush, marker, eraser, line, rectangle, ellipse, fill, and eyedropper tools
- Apple Pencil pressure support plus finger, mouse, and trackpad drawing
- Color palette, custom color picker, size, and opacity controls
- Undo and redo history
- One-tap PNG export
- Responsive layouts for phones, tablets, and desktops
- Keyboard shortcuts for desktop users

The app is plain HTML, CSS, and JavaScript with no build step or runtime dependencies. GitHub Actions deploys the `main` branch to GitHub Pages.
